# Roadmap de 200 projetos separados para portfólio

A ideia correta não é publicar 200 projetos vazios. O objetivo é ter um backlog profissional de projetos separados, por stack, e transformar os melhores em repositórios reais com README, deploy, screenshots, testes e CI/CD.

## Como usar este roadmap

- Prioridade A: projetos para fixar no perfil.
- Prioridade B: projetos bons para currículo.
- Prioridade C: projetos menores para treino e frequência de commits.
