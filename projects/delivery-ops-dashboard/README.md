## Visão geral

Dashboard operacional para acompanhar entregas locais, status dos entregadores, pedidos em risco, SLA e atrasos por região.

## English overview

Operational dashboard for local delivery teams to track couriers, risky orders, SLA and delayed deliveries by zone.

## Por que esse projeto importa para currículo

- Mostra visão de negócio e operação.
- Usa métricas úteis para delivery, logística e restaurantes.
- Demonstra layout responsivo, organização visual e priorização de informação.

## Features

- Métricas de entregas ativas
- SLA por pedido
- Lista de entregadores
- Pedidos com risco de atraso
- Tabela de regiões
- Interface responsiva

## Tech stack

- HTML
- CSS
- JavaScript

## Como executar

Abra `index.html` no navegador.
