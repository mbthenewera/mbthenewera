## Visão geral

Sistema de cardápio digital no modelo SaaS para restaurantes, hamburguerias e delivery. O projeto simula uma área administrativa para gerenciar categorias, produtos, disponibilidade e visualização pública do cardápio.

## English overview

Digital menu SaaS concept for restaurants, burger shops and delivery businesses. It simulates an admin area for managing categories, products, availability and public menu visibility.

## Por que esse projeto importa para currículo

- Mostra pensamento de produto real.
- Tem domínio de negócio claro: restaurantes e delivery.
- Demonstra separação entre painel administrativo e visualização pública.
- Pode evoluir para fullstack com login, banco de dados e upload de imagens.

## Features

- Dashboard administrativo
- Cards de indicadores
- Lista de categorias
- Produtos com status de disponibilidade
- Simulação de pedidos recentes
- Interface responsiva

## Tech stack

- HTML
- CSS
- JavaScript
- Futuro backend: Node.js + PostgreSQL

## Como executar

Abra o arquivo `index.html` no navegador.
